Programação web

Aprenda a criar sites completos, do layout ao funcionamento, e a colocá-los no ar.

O que você vai aprender

  • Estrutura de páginas com HTML

  • Como publicar seu site na internet

Para quem quer criar sites, trabalhar com web ou começar na programação. Não precisa saber nada antes.

Automações com n8n

Faça o computador trabalhar por você, ligando planilhas, e-mail, WhatsApp e outros sistemas.

O que você vai aprender

  • Como montar fluxos automáticos
  • Integrar ferramentas e planilhas
  • Conectar serviços por API
  • Usar inteligência artificial nas automações

Para quem é

Para profissionais e empreendedores que querem ganhar tempo, e para quem quer entrar na área de automação.

Desenvolvimento de softwares

O que você vai aprender

  • Lógica de programação

  • Projetos práticos do início ao fim

Para quem é

Para quem quer se tornar programador e entender como os programas são feitos por dentro.

Informática básica

Para quem é

Para iniciantes de qualquer idade, que querem perder o medo do computador.
